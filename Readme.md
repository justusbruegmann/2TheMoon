## Stocks Trading Simulator

### Description
The 2TheMoon application is a stock market and cryptocurrency trading simulation game that is targeted at novices in the trading space that can explore the subject hands-on in a gamified, low-stakes environment.

The game has a page for analyzing the current market state that changes in real-time and features for trading and managing one’s own portfolio. Furthermore, users can see their portfolio’s performance through statistics pages.

The app starts out with an analysis page that displays real-world data in real-time. Following up, the game will run on a completely virtual market simulation, influenced by random effects and the trading behavior of other players in the market.


### Techstack
- Frontend: Typescript with Vue
- Backend: Python with FastApi
- Database: Supabase (Postgres)
